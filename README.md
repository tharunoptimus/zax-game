# ZAX: Beyond the Script

A WebXR NPC demo built with A-Frame. ZAX is a robot character whose dialogue, animations, and emotions are driven live by Google's Gemini API.

## Run it

1. Open `frontend/index.html` in a browser (or visit the GitHub Pages link).
2. Paste your Gemini API key when prompted (get one free at https://aistudio.google.com/apikey).
3. Click ZAX to talk to him.

## Notes

- No backend needed, the browser calls the Gemini API directly.
- Works best on desktop Chrome or Meta Quest browser.
